💰 ClearSpend

Gestion intelligente des abonnements SaaS & dépenses récurrentes

Odoo 17 FinOps SaaS Management

🎯 Pourquoi ClearSpend ?

Les entreprises gaspillent en moyenne 30% de leur budget SaaS à cause d'abonnements oubliés, de doublons ou de licences non utilisées. ClearSpend vous aide à reprendre le contrôle de vos dépenses récurrentes directement depuis Odoo.

📊

Dashboard Intelligent

Vue d'ensemble de tous vos abonnements avec KPIs en temps réel : coût total, tendances, alertes de renouvellement.

🔔

Alertes Automatiques

Notifications avant les renouvellements, dépassements de budget et anomalies détectées automatiquement.

📈

Prévisions Budgétaires

Anticipez vos dépenses avec des projections de 3 à 24 mois basées sur vos données historiques.

🤖

Import Automatique

Importez vos abonnements depuis Excel/CSV ou extrayez automatiquement les données de vos factures par OCR.

🔄 Deux Modes Adaptés à Vos Besoins

ClearSpend s'adapte à la taille et aux besoins de votre entreprise avec deux modes distincts :

🟢 Mode Simple

Parfait pour les PME

  • Dashboard épuré avec KPIs essentiels
  • Gestion des abonnements
  • Budget global et alertes
  • Import Excel/CSV
  • Rapport PDF mensuel

🔵 Mode Avancé

Pour les grandes entreprises

  • Toutes les fonctions du mode simple
  • Workflow d'approbation multi-niveaux
  • Intégrations API (Stripe, AWS, GitHub...)
  • OCR automatique des factures
  • Gestion des contrats
  • Détection anomalies & doublons
  • Recommandations d'économies

💡 Passez d'un mode à l'autre en un clic !

Le menu et le dashboard s'adaptent automatiquement au mode choisi. Commencez en mode Simple et passez au mode Avancé quand votre entreprise grandit.

📋 Prérequis

  • Odoo 17.0 Community ou Enterprise
  • Modules requis : base, mail, web (installés automatiquement)
  • Python : openpyxl, requests

🚀 Installation

  1. Téléchargez le module depuis le Marketplace Odoo
  2. Décompressez dans votre dossier addons
  3. Mettez à jour la liste des applications dans Odoo
  4. Installez "ClearSpend" depuis le menu Applications
  5. Configurez le mode (Simple/Avancé) dans les paramètres
